Магнитометрические модели GeoMesh

Интерактивная геометрия, зависимости чувствительности, энергобюджет и многокритериальная оптимизация. Показатели имеют статус инженерных прогнозов, не результатов испытаний.

ABSOLUTE / SCALAR

GeoMesh Overhauser

Электронно-ядерная двойная резонансная поляризация. Оригинальная модель 5000 геометрий, трёхмерная сборка, Pareto front и анализ чувствительности.

VECTOR / TRIAXIAL

GeoMesh Феррозонд

Два встречновозбуждаемых сердечника Вакье на каждой оси. Три ортогональные оси, физические зависимости, модель ошибки вертикали и направления, многокритериальный Pareto.

Феррозонд определяет компоненты и направление магнитного вектора. Скалярный магнитометр измеряет модуль поля. Для географического азимута требуются привязка системы координат и магнитное склонение; направление само по себе не равно абсолютному географическому северу.
